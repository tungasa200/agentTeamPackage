# wy-ops 작업계획서 v1.0 (초안)

- 기준: 요구사항정의서 v1.0, 결정기록 D-00~D-12
- 작성: 2026-10-13, 초안 작성 erp WY-pm → S0 뒤 담당 OPS-pm
- 일정은 날짜가 아니라 순서와 완료 조건으로 관리한다.

## 1. 단계

| 단계 | 내용 | 담당 | 완료 조건 | 요구사항 |
|---|---|---|---|---|
| S0 | 도구 저장소를 자체 프로젝트로 | erp WY-pm 지휘, WY-backend2 구현(erp 쪽 마지막 도구 작업) | 패키지 전체 시험·doctor 통과, 두 VS Code 창에서 카드함 분리 확인, OPS 세션 다섯이 뜸 | SEP-01~06, DOC-01 |
| S1 | 배포 관문 | OPS-pm·OPS-review | 되돌리기 명령 문서화, 첫 배포 때 실제로 시험 | DEP-01~04 |
| S2 | worktree 동작 시험(버릴 저장소) | OPS-dev2 | 보고서 + D-05·D-08 추천안 → 사용자 카드 | WT-02·05·06·08 사전 확인 |
| S3 | 이름 격리·PC 조율 | OPS-dev1(세션 현황 표)·OPS-dev2(스크립트·doctor·메모리 관문) | erp·OPS 세션 동시 실행에서 섞임 없음, doctor가 접두사 겹침 검출 | MP-01~06 |
| S4 | worktree 도입(도구 프로젝트) | OPS-dev1(확장 경로 계산)·OPS-dev2(시작 스크립트·가드·템플릿) | 하루 실사용 + 승인 가드 잠금 시험 전부 통과 | WT-01~09 |
| S5 | erp 적용 | OPS-pm이 erp WY-pm에 요청, erp 쪽 설정·문구 변경 | erp 세션들이 각자 worktree에서 빌드·시험 | WT-10 |

순서: S0 → S1 → S2 → (S3 ∥ S4 준비) → S4 → S5. S3과 S4는 dev1·dev2가 나눠 병렬로 진행할 수 있다. 같은 파일(`session.ps1` 원본 템플릿)을 둘이 동시에 맡지 않는다.

## 2. S0 세부

1. `install.ps1 init --project C:/projects/agentTeamPackage --name agentTeamPackage --prefix OPS-`로 설정·역할 파일·pm-ops 생성. quickstart가 패키지 폴더를 거부하므로 init만 쓴다.
2. 배포 대상에서 `.claude/`·`docs/` 제외(`lib/deploy.js`), `generic.test.js` 검사 범위 조정.
3. 승인 namespace를 도구 프로젝트용으로 설정, 확장이 창마다 그 폴더를 보는지 확인.
4. `docs/`에 이 문서 둘과 진행현황·결정기록(D-00~D-12 옮김)·개정대기.
5. erp 쪽: WY-backend2·3 역할 원본(`.claude/ops/roles/`)에서 도구 범위 제거 → gen. erp CLAUDE.md 역할 표 갱신, erp 결정기록에 분리 결정 기록(WY-planner).
6. erp WY-commit이 도구 저장소 S0 커밋까지 처리하고, 이후 도구 저장소 커밋은 OPS-commit이 맡는다.

## 3. S1 되돌리기 명령(초안, S1에서 확정)

```powershell
# 설치본 버전 목록
Get-ChildItem ~/.wy-tools/wy-ops -Directory | Sort-Object LastWriteTime
# current를 이전 버전으로
~/.wy-tools/wy-ops/current/install.ps1 rollback <버전폴더>   # S1에서 추가할 명령
```

## 4. 위험과 대응

| 위험 | 정도 | 대응 |
|---|---|---|
| worktree에 훅 설정(`settings.local.json`)이 없어 승인 가드가 빠짐 | 높음 | S2에서 먼저 확인, 안 되면 시작 스크립트가 설정을 복사 |
| 버전 고정 없음(D-04): 도구 배포가 erp로 바로 퍼짐 | 높음 | S1 배포 관문, 되돌리기 명령 |
| D-04와 D-12(바로 적용)가 겹쳐 worktree 결함이 erp로 바로 옴 | 높음 | S4 검증 강화(하루 실사용 + 가드 잠금 시험 전부), erp는 설정으로 즉시 끌 수 있게 |
| 병합 충돌이 잦아 느려짐 | 중간 | 같은 파일을 두 세션에 동시에 맡기지 않는 규칙 유지 |
| worktree마다 의존성 설치로 디스크 증가 | 중간 | S2에서 측정 후 D-08 |
| pm 창·카드함이 둘이 되어 사용자 주의력 분산 | 중간 | 통합 화면은 다음 묶음 후보 |
