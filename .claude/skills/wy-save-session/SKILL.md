# wy-save-session — 세션 교체 전 저장

ECC(MIT, affaan-m/ECC) save/resume-session 형식 참고. 백그라운드 역할 세션용으로 다시 썼다: 사용자 확인을 기다리지 않는다.

## 절차
1. 파일 경로: `~/.claude/session-data/YYYY-MM-DD-<short-id>-session.tmp`(오늘 날짜). short-id는 내 역할 이름이다. 같은 날 같은 이름의 파일이 이미 있으면 `-2`, `-3`…을 붙인다. 폴더가 없으면 만든다.
2. 적을 것은 진행 중인 것만이다. 역할 설명·끝난 일은 적지 않는다(역할 파일과 `docs/진행현황.md`에 있다).
   - 미커밋 파일: 경로와 무엇을 바꿨는지 한 줄씩, 커밋 요청을 했으면 그 상태
   - 반쯤 한 작업: 어디까지 했고 무엇이 남았는지
   - 막힌 이유·기다리는 결정
   - 해 봤다가 안 된 방법과 그 이유(다시 하지 않게)
   - 다음 한 걸음: 새 세션이 바로 할 동작 하나
3. 비밀값·개인 주소·코드·비밀번호는 적지 않는다.
4. 저장한 뒤 경로를 pm 세션(`OPS-pm`)에 `SendMessage`로 알린다. 사용자 확인을 기다리지 않는다.

## 파일 형식
```
# Session: YYYY-MM-DD

**Project:** <저장소 폴더 이름만(경로 없이)>
**Worktree:** <저장소 절대 경로>
**Topic:** <역할> — <한 줄 요약>

---

## 지금 상태(진행 중인 것만)
### 미커밋 파일
### 반쯤 한 작업
### 막힌 것·기다리는 결정

## 다시 하지 않을 것
## 확인한 사실
## 다음 한 걸음
```
비어 있는 절은 "없음"으로 적는다.
